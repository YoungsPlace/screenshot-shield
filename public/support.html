SCREENSHOT SHIELD

한국어 English 简体中文

지원

현재 Screenshot Shield는 GitHub Pages에서 제공되는 모바일 웹 앱입니다. 이 페이지는 브라우저에서 스스로 해결하는 방법과 공개 저장소를 통한 비민감 문제 보고 경로를 설명합니다. 네이티브 앱 또는 앱 스토어 출시를 현재 제공되는 것으로 주장하지 않습니다.

휴대폰에서 시작하기

  1. 한국어 편집기를 열고 사진 또는 파일에서 스크린샷을 선택합니다.
  2. 자동 제안이 보이면 검토하되, 보이지 않거나 OCR을 사용할 수 없을 때도 직접 가림 영역을 추가·이동·크기 조절·삭제할 수 있습니다.
  3. 최종 미리보기를 검토하고 새 가림 결과물을 준비합니다. 이 결과물은 원본 바이트를 재사용하지 않는 새 PNG 또는 JPEG입니다.
  4. 지원되는 경우 별도의 공유 동작에서 대상 앱을 선택하거나, 다운로드/저장합니다. 공유 대상은 자체 정책에 따라 가림 결과물을 저장하거나 업로드할 수 있습니다.

이미지는 Screenshot Shield 서버로 업로드되지 않습니다. 중요한 정보는 자동 제안만 믿지 말고 공유 전 직접 확인하세요.

브라우저와 홈 화면

편집기 우선 열기

편집기 우선 주소는 마케팅 화면을 건너뛰고 일반 편집기 화면을 엽니다. 기본 주소는 언제나 한국어입니다.

홈 화면 추가

iPhone/iPad의 Safari에서는 공유 메뉴에서 홈 화면에 추가를, Android Chromium에서는 브라우저 메뉴에 제안될 때 앱 설치 또는 홈 화면에 추가를 사용합니다. 정확한 메뉴와 제공 여부는 브라우저, 운영체제 및 정책이 정합니다.

홈 화면 웹 앱은 네이티브 앱이나 앱 스토어 배포를 뜻하지 않습니다. 웹에는 서비스 워커와 오프라인 지원이 없으므로 오프라인 작동을 기대하지 마세요.

언어

한국어는 기본 언어입니다. English 및 简体中文 주소는 바로 공유할 수 있습니다. 설치된 홈 화면 웹 앱에서는 마지막으로 명시적으로 고른 언어만 screenshot-shield.locale 설정으로 기억할 수 있습니다. 저장소를 지우거나 사용할 수 없으면 한국어로 돌아갑니다. 일반 빈 주소는 저장된 언어를 읽지 않습니다.

일반 도움 및 버그 보고

GitHub에 접근할 수 있으면 공개 저장소에서 문서와 알려진 변경 사항을 확인하고, 민감한 내용이 없는 재현 가능한 문제는 Issues에 제출하세요. 계정이 필요할 수 있으며 GitHub의 가용성과 정책이 적용됩니다.

포함할 정보

  • 사용 중인 화면: 웹, 홈 화면 웹 앱, 또는 (향후 별도로 출시된 경우에만) 네이티브 앱
  • Screenshot Shield 버전 또는 배포 식별자, 전체 페이지 주소와 lang 값
  • 기기 모델, 운영체제와 버전, 브라우저와 버전
  • 재현 단계, 기대한 결과, 실제 결과, 오류 메시지 및 발생 시각
  • 원본 이미지·비밀·토큰·개인정보를 포함하지 않는 가려진 또는 합성된 증거

보안 및 개인정보 문제

원본 스크린샷, 자격 증명, 실제 비밀 또는 공격 페이로드를 공개 Issues에 올리지 마세요. 예상치 못한 네트워크 요청, 이미지 저장, 공유 경계 또는 언어 저장소 문제는 보안 정책의 비공개 보고 절차를 따르세요.

개인정보 처리방침에는 로컬 처리, 다운로드/공유 경계 및 계획된 네이티브 캐시의 제한이 설명되어 있습니다.

응답 기대치

지원은 공개 저장소의 유지 관리 가능 여부에 따라 처리됩니다. 동기식 지원, 특정 응답 시간, 문제 확인 또는 해결을 약속하지 않습니다. 보안 보고도 공개 Issue 대신 정책에 지정된 경로를 사용하세요.

Support

Screenshot Shield is currently a mobile web app served on GitHub Pages. This page explains browser self-help and a public-repository route for non-sensitive reports. It does not claim a native app or app-store release as currently available.

Start on a phone

  1. Open the English editor and choose a screenshot from Photos or Files.
  2. Review any automatic suggestions, but add, move, resize, or remove manual redaction regions whenever OCR is unavailable or a suggestion is missing.
  3. Review the final preview and prepare a new redacted output. It is a new PNG or JPEG and does not reuse the source bytes.
  4. Where supported, choose a destination in a separate Share action, or download/save the output. A destination may store or upload the redacted output under its own policy.

Screenshot Shield does not upload images to an app server. Do not rely on automatic suggestions alone for important information; inspect the result before sharing.

Browser and home screen

Open editor first

The editor-first URL bypasses the marketing view and opens normal editor chrome. The bare address always defaults to Korean.

Add to home screen

In Safari on iPhone or iPad, use Share then Add to Home Screen. In Android Chromium, use Install app or Add to Home screen when the browser menu offers it. Exact wording and availability are controlled by your browser, operating system, and policy.

A home-screen web app is not a native app or an app-store distribution. The web app has no service worker or offline support, so do not expect it to work offline.

Language

Korean is the default language. The 한국어 and 简体中文 URLs are direct, shareable links. An installed home-screen web app may remember only the last explicitly selected language in the screenshot-shield.locale preference. It returns to Korean if storage is cleared or unavailable. A normal bare URL never reads that preference.

General help and bug reports

When GitHub is reachable, use the public repository for documentation and published changes. Submit reproducible, non-sensitive bugs through Issues. A GitHub account may be required, and GitHub availability and policies apply.

Include these details

  • The surface you used: web, installed home-screen web app, or a native app only if it has separately been released
  • Screenshot Shield version or deployment identifier, complete page URL, and lang value
  • Device model, operating-system version, browser, and browser version
  • Steps to reproduce, expected and actual behavior, any error message, and when it occurred
  • Only redacted or synthetic evidence—never a source image, secret, token, or personal data

Security and privacy concerns

Do not post source screenshots, credentials, real secrets, or exploit payloads in public Issues. For unexpected network activity, image persistence, a share-boundary concern, or a locale-storage issue, use the private reporting process in the security policy.

The privacy policy explains local processing, the download/share boundary, and the limited planned-native cache boundary.

Response expectations

Support is handled as repository maintenance permits. We do not promise synchronous support, a particular response time, acknowledgement, or resolution. Use the security-policy path rather than a public Issue for a security report.

支持

Screenshot Shield 当前是在 GitHub Pages 上提供的移动网页应用。本页面说明浏览器自助方式，以及通过公开仓库提交非敏感报告的路径；不宣称原生应用或应用商店版本目前可用。

在手机上开始

  1. 打开简体中文编辑器，然后从照片或文件中选择截图。
  2. 检查自动建议；OCR 不可用或漏掉内容时，仍可手动添加、移动、调整大小或删除打码区域。
  3. 检查最终预览并准备新的打码输出。它是新的 PNG 或 JPEG，不会复用原始字节。
  4. 在支持时，通过单独的“分享”操作选择接收方，或下载/保存输出。接收方可能按其自身政策保存或上传打码输出。

Screenshot Shield 不会把图片上传到应用服务器。对于重要信息，请不要只依赖自动建议；分享前务必检查结果。

浏览器与主屏幕

直接打开编辑器

编辑器优先地址会跳过营销页面并打开普通编辑器界面。无参数地址始终默认韩语。

添加到主屏幕

在 iPhone 或 iPad 的 Safari 中，使用“分享”然后选择添加到主屏幕；在 Android Chromium 中，当浏览器菜单提供时，选择安装应用或添加到主屏幕。具体菜单文字与可用性由浏览器、操作系统和策略控制。

主屏幕网页应用不是原生应用，也不是应用商店分发。网页应用没有服务工作线程和离线支持，请不要期待离线可用。

语言

韩语是默认语言。한국어和English地址可直接分享。已安装的主屏幕网页应用最多只会在 screenshot-shield.locale 偏好中记住最后一次明确选择的语言。存储被清除或不可用时会回退为韩语；普通无参数地址不会读取该偏好。

一般帮助与错误报告

在 GitHub 可访问时，请通过公开仓库查看文档和已发布的变更，并通过 Issues 提交可复现、非敏感的问题。可能需要 GitHub 账户，并受 GitHub 可用性与政策约束。

请附上这些信息

  • 使用的界面：网页、已安装的主屏幕网页应用，或仅在其已单独发布时的原生应用
  • Screenshot Shield 版本或部署标识、完整页面地址与 lang 值
  • 设备型号、操作系统和版本、浏览器和浏览器版本
  • 复现步骤、预期和实际行为、错误消息以及发生时间
  • 仅提供已打码或合成的证据，绝不提供原始图片、秘密、令牌或个人数据

安全与隐私问题

请勿在公开 Issues 中发布原始截图、凭据、真实秘密或利用载荷。若发现意外网络活动、图片持久化、分享边界问题或语言存储问题，请使用安全政策中的私密报告流程。

隐私政策说明本地处理、下载/分享边界以及计划中原生缓存的有限边界。
